Política de Privacidade do Nosso Caixa

O Nosso Caixa (app.naressi.me) é um aplicativo de finanças pessoais de uso privado de Gabriel Naressi e Tainara. Não é oferecido ao público. Última atualização: 7 de outubro de 2026.

Que dados usamos

Gastos, contas, metas, faturas e transações bancárias que o casal lança ou conecta (pelo Meu Pluggy). Do Google Agenda, quando a pessoa autoriza: a lista de agendas e os eventos dos próximos 45 dias, apenas para exibir no próprio app, e uma agenda chamada "Nosso Caixa", criada pelo app, onde ele escreve as contas e lembretes financeiros.

Como guardamos

Os dados ficam num banco de dados privado (Supabase, região São Paulo), protegido por login, acessível apenas aos dois membros da casa. As credenciais do Google ficam guardadas de forma que só o servidor do app consegue ler.

Compartilhamento

Não vendemos nem compartilhamos dados com terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover

No app, em Agenda, use "Desconectar Google Agenda". Também é possível revogar o acesso em myaccount.google.com/permissions. Para apagar todos os dados, escreva para gabriel@naressi.me.
